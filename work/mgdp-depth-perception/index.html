MGDP — Generalized Depth Perception

Perception models for legged robots are usually welded to the robot they were trained on. MGDP separates the two, so the same perception front-end fine-tunes onto a new machine quickly.

Overview

MGDP is a perception-based deep reinforcement learning framework for quadruped locomotion. It uses a contrastive learning mechanism to extract highly generalized, low-dimensional terrain feature representations from multi-modal inputs — depth images and height maps — combined with an explicit depth-map denoising mechanism.

Terrain-adaptive reward functions modulate penalty strength according to terrain characteristics, which lets the policy acquire complex locomotion skills — climbing, jumping, crawling, squeezing — in a single training stage, without distillation.

Results

The pre-trained, dynamics-decoupled perception model fine-tunes quickly across quadruped morphologies. It was evaluated on nine distinct robots — A1, B1, Go1, Go2, Lite3, Spot, Aliengo, ANYmal C and Mini Cheetah — which despite large differences in dimensions and dynamics all traversed challenging terrain under the framework.
